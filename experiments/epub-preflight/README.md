# EPUB package preflight — experimental sample

An offline, Python standard-library checker for EPUB ZIP/container integrity, OPF manifest references, spine IDs, EPUB3 nav declaration and mimetype packaging. It never uploads manuscripts or sends email.

Run `python epub_preflight.py book.epub` and `python test_epub_preflight.py`. The synthetic tests check a clean EPUB and two intentionally broken references.

**Scope limits:** This is **not** EPUBCheck, KDP certification, visual rendering QA, accessibility certification, or editorial proofing. No private or copyrighted customer manuscripts were used.
